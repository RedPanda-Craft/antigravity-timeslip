QUICK START

Install in 30 Seconds.

Timeslip runs as a native plugin for BetterGravity on Antigravity 2.0.

git clone https://github.com/RedPanda-Craft/antigravity-timeslip.git

Step-by-Step Activation:

  1. Clone or copy into your BetterGravity plugins directory: %APPDATA%\BetterGravity\plugins\antigravity-timeslip.
  2. Add "antigravity-timeslip" to the "enabled" list in %APPDATA%\BetterGravity\settings.json.
  3. Antigravity hot-reloads instantly. Click the history clock icon in your titlebar to access Cockpit!
